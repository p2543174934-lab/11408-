- 互斥关系：对缓冲区的访问互斥
- 同步关系：
	- 父亲将苹果放入盘子后，女儿才能取
	- 母亲将橘子放入盘子后，儿子才能取
	- 只有盘子为空时，父亲或母亲才能放入

~~~ java
semaphore mutex = 1;//对盘子的互斥访问
semaphore apple = 0;//盘子里有几个苹果
semaphore orange = 0;//盘子里有几个橘子
semaphore plate = 1;//盘子中还可以放多少个水果
dad(){
	while(1){
		准备一个苹果；
		P(plate);
		P(mutex);
		把苹果放入盘子；
		V(mutex);
		V(apple);	
	}
}
mom(){
	while(1){
		准备一个橘子；
		P(plate);
		P(mutex);
		把橘子放入盘子;
		V(mutex);
		V(orange);
	}
}
daughter(){
	while(1){
		P(apple);
		P(mutex);
		从盘中取出苹果;
		V(mutex);
		V(plate);
		吃掉苹果;
	}
}
son(){
	while(1){
		P(orange);
		P(mutex);
		从盘中取出橘子;
		V(mutex);
		V(plate);
		吃掉橘子;
	}
}
~~~

>[!note]
>**可不可以不要互斥信号量mutex?**
>- 如果缓冲区的大小为1，在任何时刻最多只有一个进程的P操作不会被阻塞，所以当缓冲区大小为1是可以的；
>- 如果盘子（缓冲区容量）大于1，会出现两个进程同时访问缓冲区的情况，导致两个进程写入缓冲区的数据相互覆盖的情况
>- 同上一节：实现互斥的P操作一定在实现同步的P操作之后
