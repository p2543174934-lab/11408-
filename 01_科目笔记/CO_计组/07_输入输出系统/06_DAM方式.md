## 一、为什么需要 DMA?
**问题**:程序中断方式下,每传送一个数据(比如一个字)都要 CPU 介入:
1.中断请求 → 中断响应
2.保存现场 → 传送一个字
3.恢复现场 → 返回主程序
这对于**高速外设**(比如磁盘、网卡)来说太慢了。CPU 频繁被打断,大量时间花在"保护/恢复现场"上,真正干活的时间很少。
**DMA 的核心思路**:在内存和外设之间开一条**直接数据通道**,由一个专门的硬件(DMA控制器 / DMAC)来接管总线、搬数据。CPU 只在开始和结尾介入一下。
**适用场景**:高速外设与主存之间的成组数据传送(磁盘读写、网卡收发、SSD、声卡等)。
## 二、DMA 控制器(DMAC)的组成

| 部件              | 作用                                             |
| --------------- | ---------------------------------------------- |
| **主存地址计数器 AR**  | 存放本次 DMA 传送在主存中的起始地址,每传送一个数据自动 +1              |
| **传送长度计数器 WC**  | 记录还要传送多少个字(字节),每传一个 -1,减到 0 时发中断               |
| **数据缓冲寄存器 BR**  | 暂存要传送的字,起到缓冲作用                                 |
| **DMA 请求触发器**   | 外设准备好数据后，给出一个控制信号使得DMA请求触发器置位                  |
| **控制/状态逻辑**     | 负责整个 DMA 传送过程的时序和控制（指定传送方向，传送参数，请求信号和响应信号协调同步） |
| **中断机构**        | 一批数据传完后向 CPU 发中断                               |
| **设备地址寄存器 DAR** | 存放 I/O 设备的设备号或寻址信息(选做,部分 DMAC 有)               |

## 三、DMA 的三种工作方式(传送方式)

### 1. 停止 CPU 访问主存(独占总线)

- DMAC 一拿到总线权,就**一直占着不放**,直到这批数据全传完
- CPU 整个过程**完全不能访问主存**,只能干些不访存的内部运算
- **优点**:控制简单,适合高速成组传送
- **缺点**:CPU 利用率低,就算 I/O 设备在准备数据,CPU 也只能干等着

### 2. 周期挪用 / 周期窃取(最常用 ✅)

- DMAC **每次只挪用 1 个存取周期**,传完一个字就还回总线
- CPU 平时正常访存;DMAC 需要时才"偷"一个周期
- 可能遇到的 3 种情况:
    - **CPU 不访存** → 不冲突,DMAC 直接用
    - **CPU 正在访存** → 等 CPU 这个存取周期结束再挪用
    - **CPU 和 DMAC 同时要访存** → **DMAC 优先**(I/O 数据等不及,丢了就没了)
- **优点**:既不影响 I/O,又不让 CPU 闲死,综合效果好
- **缺点**:每挪一次都要做"申请总线 → 归还总线"的切换,有点开销

### 3. DMA 与 CPU 交替访问

- 把一个存取周期分成两个**时间片**:一个给 CPU,一个给 DMA
- 双方轮流来,**互不打扰**
- **优点**:不需要总线申请/归还过程,效率高
- **缺点**:硬件复杂;而且因为 I/O 数据是随机的,分给 DMA 的时间片可能浪费(没数据可传时也轮空)
- **适用**:CPU 工作周期比主存存取周期长的情况

## 四、DMA 传送的三个阶段
### 阶段 1:预处理(CPU 执行,程序方式)

由 CPU 执行几条 I/O 指令,告诉 DMAC:

- 传送方向(从外设到主存 / 从主存到外设)
- 主存缓冲区起始地址 → 送入 AR
- 传送的数据总量 → 送入 WC
- 启动外设
### 阶段 2:数据传送(DMAC 接管,硬件完成)⭐

- DMAC 获得总线控制权
- 从外设/主存读一个数据 → 放入 BR → 写到主存/外设
- AR +1,WC -1
- 重复直到 WC = 0
### 阶段 3:后处理(CPU 执行,中断方式)

DMAC 通过中断机构通知 CPU:"传完了" CPU 响应中断,执行中断服务程序:

- 校验数据
- 决定是否继续传送
- 出错则转错误处理

## 五、DMA 接口的两种类型

### 1. 选择型 DMA 接口

- 物理上可连多个外设,**逻辑上同一时刻只能服务一个**
- 通过在预处理时把"设备号"写入 DAR 来选中具体设备
- 适用:**高速设备**(磁盘、磁带)

### 2. 多路型 DMA 接口

- 物理上连多个外设,**逻辑上也允许多个同时工作**
- 各设备以字节交叉的方式分时传送
- 每个设备各自有独立的 AR、WC 等寄存器组
- 适用:**多个中低速设备同时工作**
