## 一、I/O 接口概述

**定义**：I/O 接口（也称 I/O 控制器）是**主机与外部设备之间的交接界面**，用于实现二者之间的信息交换。

**为什么需要接口**？ 外设种类繁多，在**工作方式、数据格式和工作速度**等方面差异显著，接口正是为弥合这些异构性而设置的。

## 二、I/O 接口的功能（5 大功能）

|序号|功能|说明|
|---|---|---|
|1|**地址译码与设备选择**|CPU 发出 I/O 请求时，会同时提供目标外设的地址码；接口对地址译码并产生设备选择信号，确保主机仅与指定外设通信|
|2|**通信联络与时序协调**|主机与外设速度通常不匹配；接口通过**握手信号**或**状态轮询**机制动态协调双方节奏|
|3|**数据缓冲**|接口设置**数据缓冲寄存器**，暂存传输数据，避免因速度不匹配导致数据丢失|
|4|**信号格式转换**|完成电平转换、并/串或串/并转换、模/数或数/模转换等物理兼容工作|
|5|**控制命令与状态信息传递**|CPU 通过**控制寄存器**写命令字（如"启动"）控制外设；外设通过**状态寄存器**反馈状态（如"就绪"）。外设主动通知 CPU（如"数据到达"）时，接口可发出**中断请求**|

## 三、I/O 接口的基本结构

### 1. 内部三大寄存器（也成为IO端口）

接口通过 **I/O 总线**与 CPU 和内存相连，内部主要包括三类寄存器：

| 寄存器         | 作用                | 访问方向    |
| ----------- | ----------------- | ------- |
| **数据缓冲寄存器** | 暂存 CPU 与外设之间传送的数据 | 双向（读/写） |
| **状态寄存器**   | 记录接口及外设的当前状态      | 仅 CPU 读 |
| **控制寄存器**   | 保存 CPU 发给外设的控制命令  | 仅 CPU 写 |

> ⚠️ **注意**：状态寄存器和控制寄存器访问方向相反，访问时间错开，因此**可复用同一端口地址**——读操作访问状态，写操作访问控制。

### 2. 三类信号线

- **数据线**：传送读/写数据、状态信息、控制信息以及**中断类型号**（在向量中断中）
- **地址线**：指定要访问的 I/O 接口内部寄存器的**端口地址**
- **控制线**：传送**读/写控制信号**（区分寄存器访问方向），以及中断请求与响应信号、总线仲裁信号和设备握手信号

### 3. I/O 控制逻辑的功能

1.对控制寄存器中的命令字**译码**，生成控制信号经外设界面控制逻辑送至外设
2.输出时，将数据缓冲寄存器内容发送给外设；输入时，将外设数据写入数据缓冲寄存器
3.实时采集外设状态，并更新至状态寄存器

> 对上述寄存器的访问通过**专用指令**完成，这类指令称为 **I/O 指令**。在采用独立 I/O 地址空间的体系结构（如 x86）中，I/O 指令通常为**特权指令**，仅限操作系统内核使用。

## 四、I/O 接口的类型

按不同角度，I/O 接口可分类如下：

| 分类角度                  | 类型                                |
| --------------------- | --------------------------------- |
| **按数据传送方式**（外设与接口一侧）  | 并行接口（一字/字的所有位同时传送）、串行接口（一位一位有序传送） |
| **按主机访问 I/O 设备的控制方式** | 程序查询方式、中断方式、DMA 方式                |
| **按功能灵活性**            | 可编程接口（可通过编程改变接口功能）、不可编程接口         |

## 五、I/O 端口及其编址 

### 概念区分

- **I/O 端口**：指 I/O 接口电路中可被 CPU 直接访问的**寄存器**，主要包括**数据端口**（支持读/写操作）、**状态端口**（仅支持读操作）、**控制端口**（仅支持写操作）
- **端口与接口**：端口是接口内**不可少**的寄存器；一个接口对应**唯一一个端口地址**

### 两种编址方式

#### （1）独立编址（I/O 独立空间 / 端口编址）

- **特点**：I/O 端口地址空间与内存地址空间**相互独立**
- **优点**：
    - I/O 端口地址可少于内存单元，地址线较少，寻址速度快
    - 译码电路简单，便于使用专用 I/O 指令
    - 程序中 I/O 操作清晰，便于阅读与调试
- **缺点**：
    - I/O 指令功能有限，效率低
    - 增加了控制逻辑的复杂性
    - 需专门提供存储器读/写和 I/O 读/写两组控制信号
- **应用**：x86 系列（IN/OUT 指令）

#### （2）统一编址（存储器映射 I/O / 内存映射 I/O）

- **特点**：将 I/O 端口地址**合并**到主存地址空间中，即 I/O 端口与内存单元**共享同一地址空间**
- **优点**：
    - **无需专用 I/O 指令**，使用普通访存指令即可访问 I/O 端口
    - 访问 I/O 端口可使用**丰富的存储器寻址方式**（如直接/间接寻址）
    - I/O 端口可获得较大的编址空间，便于系统扩展
    - 保护机制可由虚拟存储管理系统统一实现，**无须额外硬件支持**
- **缺点**：
    - I/O 端口**占用主存地址空间**，使主存容量**减小**
    - 译码电路相对复杂，**可能降低译码速度**
    - 需根据完整地址判断是否为 I/O 区域，增加判断开销
