## 王道书给的常用指令

1. 备注：
	1. < reg>：表示任意寄存器，其后带数字，则指定其位数
	2. < mem>表示内存地址
	3. < c o n>表示8，16，32位常数
 2. 数据传送指令
	1. mov指令，将第二个操作数复制到第一个操作数
	   >[! example]
	   >mov < reg>,< reg>
	   >mov < reg>,< mem>
	   >mov < mem>,< reg>
	   >mov < reg>,< con>
	   >mov < mem>,< con>
	   >举例：mov eax, ebx;
	   >双操作数的指令的两个操作数不能同时为内存
	
	2. push指令，将操作数压入栈中，常用于甘薯调用和现场保护。ESP是栈顶
	  >[!example]
	   >push exa
	   >push [ var ]
	   
	   
	3. pop指令，与push指令相反，从栈中弹出数据
	   >[!example]
	   >pop eax
	   >pop [ebx]
