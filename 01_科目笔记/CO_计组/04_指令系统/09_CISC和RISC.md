- CISC：Complex Instruction Set Computer
- 设计思路：一条指令完成一个复杂的基本功能
- 代表：x86架构
- 80-20规律：典型程序中80％的语句仅使用处理机20％的指令


- RISC：Reduced Instruction Set Computer
- 设计思路：一条指令完成一个基本动作，多条指令组合完成一个复杂的基本功能
- 代表：ARM架构


- CISC的思路：除了提供整数的加减乘除指令之外，还提供矩阵加法指令，矩阵减法，乘法
- 一条指令可以由一个专门电路完成
- 有的复杂指令用纯硬件实现困难，采用存储程序的设计思想，由一个比较通用的电路配合存储部件完成一条指令

- RISC的思路：只提供整数的加减乘指令
- 一条指令一个电路，电路设计相对简单功耗更低，“并行”，“流水线”
