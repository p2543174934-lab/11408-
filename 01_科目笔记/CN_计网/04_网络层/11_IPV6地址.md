- IPV6地址 = 128位
- 彻底解决地址不够用的问题
- 每个设备都能拥有全球唯一的IP地址
- IPV6地址采用冒号十六进制记法，总共128bit地址，16bit为一段，记录为16进制，段间以冒号分隔，总共8段
- 压缩记法：
	- 去除每个分段的前导0
	- 用双冒号::替代连续出现的多个0
		- 一次地址只能出现一次双冒号，否则会有歧义
- IPV6地址分配
	- 也支持无分类编址CIDR，前面nbit分配后不能动，后面可以自行
	- ![[Pasted image 20260711203057.png]]
- IPv6地址空间很大，可以划分更多的层级
- 支持即插即用（IP地址自动配置） -- 一台主机接入网络后，只需向路由器确认本网络前缀，就可以给自己分配IP地址（通常以自身的MAC地址作为接口标识符）
- IPv6可以不使用DHCP，在一些IP地址安全性高的地方，也支持使用DHCP统一管理

>[!note]
>- 更大的地址空间
>- 扩展的地址层次结构
>- 灵活的首部格式
>- 改进的选项
>- 允许协议继续扩充
>- 支持即插即用
>- 支持资源的预分配
>- IPv6只有源主机可以分片，不允许中间路由器进行
>- IPv6首部长度固定40B
>- 增大了安全性

- IPv6的数据报![[Pasted image 20260711204302.png]]![[Pasted image 20260711204351.png]]
	- 版本：占4位，指明IP协议的版本
	- 通信量类，占8位，区分不同IPv6数据报的类别或优先级
	- 流标号：占20位，IPv6提出流的抽象概念
		- 流是互联网上从特定源点到特定终点的一系列数据报，路径上的路由器可据此提供特定的服务质量保证。所有属于同一个流的数据报都具有相同的流标号
	- 有效载荷长度：16位，表示IPv6数据报中除了基本首部后的字节数
	- 下一个首部：8位，若无扩展首部，则标识上层协议类型；若存在扩展首部，则标识紧随其后的第一个扩展首部的类型
	- 跳数限制：8位，等同TTL
	- 源地址目的地址：128bit
