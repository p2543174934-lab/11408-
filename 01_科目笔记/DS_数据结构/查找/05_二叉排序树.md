- 二叉排序树的简称是BST
- 二叉排序树左＜根＜右
- 对二叉排序树进行中序遍历可以得到一个递增的有序关键字序列
~~~ c
BSTNode *BST_Search(BitTree T,ElemType key){
	while(T!=NULL && key != T->data){
		if(key<T->data) T = T->lchild;
		else T = T-> rchild;
	}
	return T;
}
~~~
## 二叉排序树的插入
- 当查找失败时，才进行插入
- 新插入的节点在插入完成后一定是一个叶结点
~~~ C
int BST_Insert(BiTree &T,KeyType k){
	if(T == NULL){
		T = (BitTree)malloc(sizeof(BSTNode));
		T -> data = k;
		T -> lchild = T -> rchild =NULL;
		return 1;
	}
	else if(k==T->data)//存在相同关键字，插入失败
		return 0;
	else if(k<T->data)
		return BST_Insert(T->lchild,k);
	else
		return BST_Insert(T->rchild,k);
}

~~~
## 二叉排序树的删除
**若被删节点时叶结点，直接删除**
**若节点只有一棵非空子树，则将其唯一子树上移**
**若节点同时具有左右两棵子树，则可用直接前驱或直接后继来替代**
>[!note]
>直接后继：右子树中的最小节点，即右子树中最左节点，按照中序访问的第一个节点
>直接前驱：左子树中的最大节点，即左子树中最右节点，按照中序访问的最后一个节点

## 二叉排序树查找效率
- 取决于树高，左右子树高度差不超过1，则$O(log_2n)$，在最坏情况下，会形成单支树，此时高度为n，性能显著下降
[[03_折半查找]]
>[!compare]
>二分查找的判定树唯一，而二叉排序树不唯一，所以在极端情况，也就是单支树情况下，二叉排序树效率低
>当表为静态查找表，用顺序存储并且二分查找
>当表为动态查找表，选择二叉排序树
