也称二分查找，适合关键字有序的顺序表
~~~ c
int Binary_Search(SSTable L,ElemType Key){//升序排列的代码
	int low = 0;
	int high = L.TableLen-1;
	int mid;
	while(low < high){
		mid = (low + high) / 2;
		if(L.elem[mid] == Key){
			return mid;
		}
		else if(L.elem[mid] > Key){
			high = mid - 1;
		}else{
			low = mid + 1;
		}
	}
	return -1;
}
~~~
在选取中间节点，可以对除法后的结果进行向下取整或者向上取整，但确定之后，我们就要在查找中持续采用相同的取整方式
## 折半查找的判定树
![[折半查找判定树.excalidraw|100%]]

显然这个判定树是一个[[06_平衡二叉树]]，若当前low和high之间有奇数个元素，则mid分隔开的左右两边元素个数相同；若有偶数个，则相差一
若使用向下取整，则右子树-左子树 = 0/1；若向上取整，则相反

在等概率情况下，折半查找的的ASL为$ASL = \frac{1}{n}\sum_{i=1}^{n}l_i = \frac{n+1}{n}log_2{(n+1)}-1\approx log_2{(n+1)}-1$

>[!caution]
>1.折半查找一定比顺序查找快？ ×
>	eg:当查找元素是第一个，顺序查找直接找到，但是对于折半查找则不是
>2. 由于折半查找需要随机访问任意位置的元素，所以仅适用于顺序存储，而不适用链式存储
