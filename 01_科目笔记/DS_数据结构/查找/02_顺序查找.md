## 一般线性表的顺序查找
~~~ C
typedef struct{
	ElemType *elem;
	int TableLen;
}SSTable;
int Search_Seq(SSTable ST,ElemType key){
	ST.elem[0]= key;//哨兵位置，采用哨兵位的顺序查找第一一个位置为空，置为key
	for(int i = St.TableLen - 1;ST.elem[i] != key ;i--);
	return i;//成功返回元素下标，失败返回0；
}
~~~
>[!note]
>引入哨兵的目的是避免在循环中反复判断数组下标是否越界
>在使用中也可以不用哨兵这样子数组的第0位可存元素，但是在每次循环都需要判断i是否大于数组长度

- $ASL_{成功}=\sum_{i=1}^{n}P_i(n-i+1)$
- 对于每个元素出现概率相等时$ASL_{成功}=\sum_{i=1}^{n}P_i(n-i+1)=\frac{n+1}{2}$
>[!tip]
>按照查找概率由大到小重新排列，使得高频元素靠近起点，尽可能降低平均查找长度
## 有序线性表的顺序查找
- 假设线性表按升序排列，在查找时候，若发现key已经大于现在的值，直接停止，大大降低了查找失败时的ASL
>[! 补充]
>可以使用判定树来描述查找过程，在判定树中，使用圆形节点表示实际存在的元素；矩形节点称为失败节点（若有n个节点，则对应有n+1个失败节点）
>一个成功节点的查找长度 = 自身所在层数
>一个失败节点的查找长度 = 父节点所在的层数

- 在有序线性表中，查找成功的ASL和一般线性表相同
- 在等概率情况下查找失败的查找长度$ASL_{失败} = \sum_{j=1}^{n}q_j(l_i-1) = \frac{1+2+ ··· + n + n}{n+1} = \frac{n}{2}+\frac{n}{n+1}$
