空间：O(1)
时间：O($n^2$)【最好的情况下是n】
稳定性：稳定
适用性：顺序存储和链式存储的线性表

``` c++
#include <iostream>
// 交换两个整数的值
// 使用引用传递 (int &a, int &b) 以直接修改实参
void swap(int &a, int &b) {
    int temp = a;
    a = b;
    b = temp;
}
// 冒泡排序算法
void BubbleSort(int A[], int n) {
    for (int i = 0; i < n - 1; i++) {
        bool flag = false;            // 表示本趟冒泡是否发生交换的标志
        for (int j = n - 1; j > i; j--) { // 一趟冒泡过程（从后往前）
            if (A[j - 1] > A[j]) {    // 若为逆序则交换
                swap(A[j - 1], A[j]);
                flag = true;
            }
        }
        if (flag == false) {          // 本趟遍历后没有发生交换，说明表已经有序
            return;
        }
    }
}

// 测试函数（可选）
int main() {
    int arr[] = {64, 34, 25, 12, 22, 11, 90};
    int n = sizeof(arr) / sizeof(arr[0]);
    
    BubbleSort(arr, n);
    
    std::cout << "排序后的数组: ";
    for (int i = 0; i < n; i++) {
        std::cout << arr[i] << " ";
    }
    return 0;
}
```

>[!note]
>每次swap即交换一次位置，元素移动了3次
>若在一趟排序中未发生交换，可以直接结束，已经有序
>冒泡排序每趟产生的子序列具有全局有序性，冒泡排序每趟可以将一个元素精准放到其最终位置
